# Upgrade to 0.2.1

From 0.2.0 · 2026-10-02 · [all guides](./index.md)

0.2.1 rewords two breadcrumbs in the `justfile` pack. No changes are needed: the config, the exports, the hook registrations and `.githooks/pre-commit` are the same as in 0.2.0.

## 1 · Install 0.2.1

```sh
npm i -D @jawache/flow@0.2.1    # when flow is a dev dependency of the repo
npm i -g @jawache/flow@0.2.1    # when `flow` is installed globally
```

## 2 · Required changes

None.

## 3 · What now blocks or passes differently

Nothing blocks or passes differently. Two breadcrumb texts changed, and a breadcrumb is a note that never refuses anything:

- **`justfile.orientation`**, shown at `session`, now says a script earns a recipe only when it is run regularly, across tasks. It used to say that anything a person should also run becomes a recipe.
- **`justfile.toolsHome`**, shown at `touch` on the tools folder, now lists a seed and a release's data step as one-offs that get no recipe.

A repo that binds `pack(justfile, …)` without overriding these two entries shows the new text. An agent may now argue against adding a recipe for a one-off script.

## 4 · Optional

- If the repo added recipes for one-off scripts (a seed, a backfill, a data fix), remove those recipes from the justfile and keep the scripts.
- If the repo overrode `justfile.orientation` or `justfile.toolsHome` only to work around the old wording, remove the override.

## 5 · Verify

```sh
flow status    # green
flow test      # every case green
```
