# Upgrade to 0.1.1

From 0.1.0 · 2026-09-16 · [all guides](./index.md)

0.1.1 adds two things a config can use: its own ast-grep grammar, and a breadcrumb shown before a shell command. No changes are needed: no pack changed, nothing was removed from the exports, and the hook registrations and `.githooks/pre-commit` are the same as in 0.1.0.

## 1 · Install 0.1.1

```sh
npm i -D @jawache/flow@0.1.1    # when flow is a dev dependency of the repo
npm i -g @jawache/flow@0.1.1    # when `flow` is installed globally
```

## 2 · Required changes

None.

## 3 · What now blocks or passes differently

Nothing.

## 4 · Optional

- **Declare an ast-grep grammar** for a language with no published grammar package, such as astro, vue or svelte. Pass it in the second argument to `defineConfig`:

  ```ts
  export default defineConfig([pack(house)], {
    grammars: [{ name: "astro", libraryPath: "grammars/astro.dylib", extensions: ["astro"] }],
  });
  ```

  `flow status` then prints a `grammars` line. If the library file is missing, that line is red, and every rule on that language refuses.
- **Show a note before a shell command runs:** `breadcrumb().at(command).on("npm install*", "npm i *").text("…")`. `.on(…)` matches the command line. Without `.on(…)` the note is shown on every shell command. It uses the existing `PreToolUse` registration, so `flow init` does not need to run again.
