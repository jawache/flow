textBan

reads: file body · fires at: write · commit · 2026-09-06

Bans a word or pattern in text — prose, config, comments, anything. Each regex is tried against every line; a match is a finding naming the line. Case-sensitive. For code shapes prefer astGrep, which parses the tree and cannot false-match inside a string or a comment.

Options

KeyTypeRequiredMeaning
banlist of regexyesone pattern per concern; any line matching any of them blocks

Example

noTodo: guardrail()
  .at(write, commit)
  .on("src/**/*.ts")
  .check(textBan({ ban: ["\\bTODO\\b"] }))
  .message("No TODOs — do it now, or track it properly.")
  .test({ pass: [{ path: "src/x.ts", content: "const x = 1;" }], block: [{ path: "src/x.ts", content: "// TODO: later" }] }),
