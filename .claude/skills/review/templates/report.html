work-125 spent a fifth of its build fixing tests that a restyle should not have broken

could have cost lessup to $12 of $106.65work
What happened
The issue restyled the web pages. The tests for those pages compare the page's HTML, style names included. Each restyle turned them red, and the builders edited the expected HTML by hand until they passed.
Shown by
423 test runs, 130 of them failed. 205 of the builders' 1,099 requests fell between a failed run and the next passing one.
Root cause
A test that holds the page's markup fails when the look changes, not when the behaviour breaks.
Intent
Not met. The tests are there to catch broken behaviour.
Fix
Rung 3, a guardrail: refuse a web test that matches on a style name. The tests that do so today change first.
How sure
The rounds are counted. $12 is the most it could be. The guardrail stops style-name matches for certain, and does not stop a test that compares a whole page.
The issue it would become: "No web test matches on a style name", in work.Reply file 1 · discuss 1 · skip 1
